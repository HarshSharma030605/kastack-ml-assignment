L2 CANDIDATE DATASET PACKAGE

Use this package together with the original 900-message L1 dataset and your own L1 outputs.

l2_messages.csv contains 180 new chronological development messages, MSG_0901 through MSG_1080. Process them after L1 messages while building L2.

For the recorded demonstration, load l2_demo_messages.csv as a new unseen batch and visibly process it through the application. Then run every query in l2_demo_queries.csv. Do not manually hardcode results for these messages or queries.

The demo file contains 24 records covering priority changes, completion/cancellation, rescheduling, semantic relationships, privacy routes, ambiguous updates, new items, and insufficient evidence.

Do not publish either dataset in a public repository. Mask sensitive-looking values in all screenshots, logs, hosted output, and recordings.
